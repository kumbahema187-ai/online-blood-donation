# 🩸 Online Blood Donation Portal

A full-stack web application developed using Flask and SQLite to connect blood donors with patients based on blood group and location. The system provides donor management, blood request handling, profile management, and an administrative dashboard.

## 📌 Project Overview

The Online Blood Donation Portal is designed to simplify the process of finding suitable blood donors and managing blood donation requests.

The application allows users to register as donors, search for donors based on blood group and location, manage profiles, and submit blood requests. An admin dashboard provides centralized management of donors and blood requests.

---

## ✨ Features

- 👤 User registration and authentication
- 🩸 Donor registration and management
- 🔍 Search donors by blood group and location
- 📋 Create and manage blood requests
- 👤 Donor profile management
- 🛡️ Admin dashboard
- 📊 Donor and blood request management
- 🗄️ SQLite database integration
